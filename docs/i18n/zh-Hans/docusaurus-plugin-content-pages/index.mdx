<dfk-features section-title="my_extension 能给你什么">

<dfk-feature icon="lucide:braces" title="直接用 SQL 调用">
my_greet、my_greet_checked 与 my_sum 就是普通的 DuckDB 函数：放进任意查询，和内置函数一起用，调用处不需要 import 任何东西。
</dfk-feature>

<dfk-feature icon="lucide:package" title="一行装好">
INSTALL my_extension FROM community; 再 LOAD my_extension; —— 构建签过名、且与你的 DuckDB 版本和平台匹配，所以不用加 -unsigned。
</dfk-feature>

<dfk-feature icon="lucide:monitor-down" title="每个版本都有各平台产物">
每个版本都会把各平台各一份 .duckdb_extension 挂到 GitHub Release 上，LOAD 可以直接按 URL 取，中间不用先下载。
</dfk-feature>

<dfk-feature icon="lucide:shield-check" title="DuckDB 1.4 或更新">
基于 DuckDB 的 C 扩展 API 构建，一个二进制就能加载进 DuckDB 1.4 及之后的版本，不需要重新编译。
</dfk-feature>

<dfk-feature icon="lucide:play" title="例子就地能跑">
本站每个例子都在你的浏览器里用 DuckDB-Wasm 真跑 —— 在函数页点一下「执行」就能看到真实结果。
</dfk-feature>

<dfk-feature icon="lucide:scale" title="MIT 许可">

</dfk-feature>

## 装一次，之后就在 SQL 里调用

扩展加的就是一批普通的 SQL 函数，调用处不用 import 任何东西。左边装一次，右边就能在任何能写 DuckDB 函数的地方用它。

<div className={styles.codeGrid}>

```sql title="duckdb"
-- once per installation, then once per session
INSTALL my_extension FROM community;
LOAD my_extension;
```

<div className={styles.codeColumn}>

```sql title="duckdb"
SELECT my_greet_checked('world');  -- Hello, world!
SELECT my_greet_checked('');       -- NULL
SELECT my_sum(x) FROM (VALUES (1.5::DOUBLE), (2.5::DOUBLE)) t(x);
-- 4.0
```

注释就是每次调用的返回值 —— 最后一行是对两行数据真实求和的结果。
