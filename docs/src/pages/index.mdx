## Install once, then call it from SQL

The extension adds ordinary SQL functions, with nothing to import at the call site. Install it once (left), then use the functions anywhere a DuckDB function is allowed (right).

<div className={styles.codeGrid}>

```sql title="duckdb"
-- once per installation, then once per session
INSTALL my_extension FROM community;
LOAD my_extension;
```

<div className={styles.codeColumn}>

```sql title="duckdb"
SELECT my_greet_checked('world');  -- Hello, world!
SELECT my_greet_checked('');       -- NULL
SELECT my_sum(x) FROM (VALUES (1.5::DOUBLE), (2.5::DOUBLE)) t(x);
-- 4.0
```

The comments are what each call returns — and the last one is a real sum over two rows.
